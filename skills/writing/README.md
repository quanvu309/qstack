# Viết

Skill cho chữ tiếng Việt: bài viết, email, tài liệu, chữ trên giao diện.

## Gọi tay

Chỉ chạy khi bạn gõ tên skill (Claude Code: `disable-model-invocation: true`; Codex: `policy.allow_implicit_invocation: false` trong `agents/openai.yaml`).

- **[vi-setup](./vi-setup/SKILL.md)**: Chốt giọng văn tiếng Việt của dự án một lần (xưng hô, văn phong, kiểu đặt dấu, cách ghi tiền và ngày) để mọi skill viết giống nhau.

## Agent tự gọi

Agent tự gọi khi việc đang làm khớp với mô tả. Gõ tên skill để gọi thẳng cũng được.

- **[vi-writing](./vi-writing/SKILL.md)**: Viết, dịch và sửa tiếng Việt cho ra giọng người Việt, không mang giọng dịch.
