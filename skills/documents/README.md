# Văn bản

Skill cho văn bản hành chính và văn bản một trang, xuất ra file .docx.

## Agent tự gọi

Agent tự gọi khi việc đang làm khớp với mô tả. Gõ tên skill để gọi thẳng cũng được.

- **[vi-official-doc](./vi-official-doc/SKILL.md)**: Soạn văn bản hành chính đúng văn phong và thể thức Nghị định 30/2020/NĐ-CP, xuất ra file .docx.
- **[vi-one-pager](./vi-one-pager/SKILL.md)**: Viết tờ trình, báo cáo nhanh hay đề xuất gọn trong một trang, chi tiết dời sang phụ lục.
