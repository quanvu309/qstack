# Văn bản

Văn bản theo thể thức của cơ quan, doanh nghiệp Việt Nam.

## Agent tự gọi

Agent tự gọi khi việc đang làm khớp với mô tả. Gõ tên skill để gọi thẳng cũng được.

- **[vi-official-doc](./vi-official-doc/SKILL.md)**: Soạn văn bản hành chính đúng văn phong và thể thức, xuất ra file .docx.
- **[vi-one-pager](./vi-one-pager/SKILL.md)**: Viết tờ trình, báo cáo, đề xuất gọn trong một trang, chi tiết để ở phụ lục.
