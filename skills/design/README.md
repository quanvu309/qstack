# Thiết kế

Giao diện và dữ liệu cho người dùng Việt.

## Agent tự gọi

Agent tự gọi khi việc đang làm khớp với mô tả. Gõ tên skill để gọi thẳng cũng được.

- **[vi-typography](./vi-typography/SKILL.md)**: Chọn font và trình bày chữ để dấu tiếng Việt không mất, không chồng nhau.
- **[vi-locale](./vi-locale/SKILL.md)**: Lưu, tìm và hiển thị tên, địa chỉ, tiền, ngày tháng theo cách người Việt quen dùng.
